# Madhanesh Portfolio

A frontend-only portfolio starter built with React and Vite.

## Getting started

```sh
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build in `dist`
- `npm run preview` — preview the production build locally
- `npm run lint` — check the project with Oxlint

## Make it yours

- Edit the introduction, about section, and contact email in `src/components/`.
- Replace the sample project, skill, and experience data in `src/data/portfolio.js`.
- Update colors, type, and responsive styles in `src/index.css` and `src/App.css`.
- Update the page title and description in `index.html`.

This project uses no backend or additional runtime packages.

## Project structure

```text
src/
  components/  Reusable page sections and UI components
  data/        Portfolio content kept separate from presentation
  App.jsx      Page composition
  App.css      Portfolio component styles
  index.css    Global styles, theme tokens, and base defaults
  main.jsx     React application entry point
```
